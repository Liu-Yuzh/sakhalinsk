# Sakhalinsk

YuzhNote（Cosense）と組み合わせて使う、研究メモと身の回りの管理のための Discord Bot です。LLM は使わず、無料の公開 API と、手元で動く処理（正規表現・全文検索・OCR）だけで動きます。

機能はチャンネルごとに分かれていて、`.env` でチャンネルの ID を入れた機能だけが動きます。コマンドを打たなくても、決まったチャンネルに書くだけで使えるようにしてあります。

## 機能

### 論文（`#inbox` と論文フォーラム）
- `#inbox` に URL・arXiv・DOI を貼ると、書誌を取って Cosense にページを作ります（重複していれば作らずに知らせます）。
- 論文なら、フォーラムチャンネルに**論文ごとのスレッド**を立てます。最初の投稿に「📚積読・📖読書中・✅読了」のボタンが付き、押すと Cosense のタグ、フォーラムのタグ、ボタンの見た目がそろって変わります。読了にすると Cosense に `読了日：` の行も入ります。
- arXiv の論文は、スレッドを立てたときに PDF を取ってきて、**序論の最後の段落**（貢献のまとめ）、**結論**、**図**（キャプションの上の部分を画像にしたもの）をスレッドに投稿します。DOI の論文などは、スレッドか `#inbox` に PDF を添付すれば同じことをします。PDF は `data/papers/` に保存されます。
- `/tsundoku` で、読書中と積読の一覧を出し、メニューから状態を変えられます。
- arXiv の新着は毎朝通知し、📌で登録、👎で見送り（反応は記録しておきます）。

### 毎日のボード（`#today`）
- `#today` に書いた文が、そのままタスクになります。1行1件で、複数行なら複数件です。`金曜 発表練習` `11/20 申請` のように日付を先頭に書くと、その日のボードに出ます。
- 毎朝（`DAY_START_HOUR` 時）、その日のボードが投稿されます。タスクと習慣がボタンで並び、**押すだけで済**になります。もう一度押すと戻ります。
- 終わらなかったタスクは、翌日のボードに「（11/12から）」付きで持ち越されます。
- ボードの下のメニューから、タスクを消す・明日へ回す・日付を変える、ができます。
- 習慣は `/habit add 名前 日`（日は `毎日` `平日` `週末` `月水金` など）で登録します。ボードの上に並び、連続日数（🔥）が出ます。`HABIT_NUDGE_HOUR` 時に、まだの習慣があれば声をかけます。`/habit stats` で、4週間分の記録と30日の達成率を見られます。

### リマインダー（`#remind`）
- `明日9時 ゴミ出し` `30分後 洗濯` `毎週月曜8時 資源ごみ` `平日 8時 メール` `11/20 15:00 締切` のように書くだけで入ります。
- 時間が来るとメンションし、「完了・10分後・1時間後・明日」のボタンを出します。Bot が止まっていた間の分は、起動したときに遅れて知らせます。
- `/remind` でどのチャンネルからも入れられます。`/reminders` で一覧と取り消し。

### 家計簿（`#kakeibo`）
- レシートの写真を送ると、**写真をサーバーの `data/receipts/年-月/` に保存**し、Tesseract で読んで、合計金額・日付・店名を取り出します。
- 分類はボタンで選びます。一度選ぶと、同じ店（支店名は無視）やメモには次から自動で同じ分類が付きます。
- 読み間違いは ✏️ で直せます。写真がなくても `680 昼食` のように書けば記録できます。
- `/kakeibo` で月の集計と CSV（Excel で開ける形）を出します。

### Kindle の日替わりセール（`#kindle`）
- 毎朝 `KINDLE_HOUR` 時（初期設定は7時）に、その日の Kindle 日替わりセールの書名・価格・リンクを流します。`/kindle_now` で今すぐ流せます。
- Amazon のページから読み取っているので、ページの作りが変わると読めなくなります。そのときはチャンネルに知らせます。

### まとめて探す（`#search`）
- Discord のメッセージ、Cosense の全ページ、レシートの文字、論文 PDF の序論・結論を、一つの全文検索にまとめています。日本語の部分一致で探せます。
- Discord に貼ったリンクは、**リンク先のページのタイトルも取って一緒に入れる**ので、URL しか貼っていなくても中身の言葉で見つかります。
- `#search` に書くとそのまま検索になります（`/find` でも可）。`@cosense` `@discord` `@receipt` `@pdf` を付けると場所を絞れ、`"knowledge graph"` のように引用符で空白を含む語を探せます。
- `/triage` で、Discord に貼ったまま Cosense に入っていないリンクを並べ、ボタンで Cosense に送れます。

## はじめ方

1. Discord Developer Portal で、Bot の設定の **Message Content Intent** をオンにする。
2. Bot を招くときの権限：メッセージの送信、埋め込みリンク、ファイルを添付、メッセージ履歴を読む、リアクションの追加、スレッドでメッセージを送信、公開スレッドの作成、**メッセージの管理**（`#today` に書いた文を消してボードだけにするため）、**チャンネルの管理**（フォーラムに状態のタグを作るため。なければ手でタグ「積読」「読書中」「読了」を作る）。
3. Discord で `#inbox` などのチャンネルと、論文用の**フォーラムチャンネル**を作り、ID を `.env` に入れる。
4. サーバーに OCR を入れる（Ubuntu・Debian・Raspberry Pi OS）。

```
sudo apt install tesseract-ocr tesseract-ocr-jpn
```

5. Python のライブラリを入れて確認する。

```
.venv/bin/pip install -r requirements.txt
.venv/bin/python test_offline.py   # ok と出ればよい
systemctl --user restart sakhalinsk
```

6. 最初の一回だけ、Discord で `/reindex Cosense` と `/reindex Discord の過去のメッセージ` を実行して、検索の索引を作る。以後は自動で更新されます（Cosense は `COSENSE_SYNC_HOURS` 時間おき、Discord は書くたび）。

## 気をつけること

- **Cosense の書き換え**：状態のボタンは、Cosense のページを読んでからインポート機能で書き戻します。ボタンを押したのとほぼ同じ瞬間にブラウザでそのページを編集していると、その編集が消えることがあります。
- **Cosense 側で手でタグを変えた場合**、`/tsundoku` を開いたときに Bot の記録は Cosense に合わせて直りますが、フォーラムのタグとボタンの色はそのままです。
- **PDF の抽出**は、見出しの書き方（`1 Introduction` `2. 関連研究` など）と、図のキャプション（`Figure 1:` `図1`）から推測しています。書式によっては取れなかったり、図の範囲がずれたりします。
- **レシートの OCR** は、明るく、まっすぐ、レシート全体が写った写真ほどよく読めます。感熱紙のかすれや、しわの多いものは苦手です。
- **検索**は単語の部分一致です。3文字以上の語は全文検索の索引で速く探し、2文字以下の語は全体をなめるので、量が増えると少し遅くなります。
- **`/triage`** は Cosense の索引と照らし合わせるので、Cosense に入れた直後のリンクは、次の索引の更新（`COSENSE_SYNC_HOURS`）まで出てくることがあります。
- `DAY_START_HOUR`（初期設定は4時）までは前の日として扱います。夜中の2時に済ませた習慣は、前の日の分になります。

## ファイル

| ファイル | 中身 |
|---|---|
| `main.py` | 起動と、機能（cogs）の読み込み |
| `config.py` / `db.py` | `.env` の設定 ／ データベースの表 |
| `cogs/papers.py` | 論文の登録・フォーラム・積読・PDF |
| `cogs/arxiv.py` | arXiv の新着 |
| `cogs/today.py` | 毎日のボード（タスク・習慣） |
| `cogs/remind.py` | リマインダー |
| `cogs/kakeibo.py` | 家計簿 |
| `cogs/kindle.py` | Kindle の日替わりセール |
| `cogs/search.py` | まとめて探す・未整理のリンク |
| `sources.py` / `cosense.py` | 書誌の取得 ／ Cosense の読み書き |
| `jptime.py` / `pdftools.py` / `receipt.py` / `search_index.py` | 日時の読み取り ／ PDF ／ OCR ／ 全文検索 |
