# 📖 Sakhalinsk の使い方
基本は**決まったチャンネルに書くだけ**です。コマンドはほとんど要りません。ボタンやメニューは、Bot が出したメッセージの下に付いています。

**チャンネル**
・<#TODAY> 今日のタスクと習慣
・<#REMIND> リマインダー
・<#KAKEIBO> 家計簿
・<#INBOX> 論文・リンクの登録
・<#SEARCH> まとめて検索
・<#WATCH> arXiv の新着（毎朝）
・<#KINDLE> Kindle 日替わりセール（毎朝）
=====
## 📋 #today ― タスクと習慣
**タスクを足す**：そのまま書きます。1行が1件です。書いた文は消え、ボードに入ります。
```
論文の図を直す
金曜 発表練習
11/20 申請
```
日付を先頭に書くとその日のボードに出ます（`明日` `金曜` `11/20` `来週月曜` など）。

**済ませる**：ボードのボタンを押します。もう一度押すと戻ります。
**消す・明日へ・日付を変える**：ボードの下の「🧹 タスクを整理」から選びます。
**持ち越し**：終わらなかったタスクは、翌朝のボードに「（11/12から）」付きで出ます。

**習慣**
・足す：`/habit add 名前 日`（日は `毎日` `平日` `週末` `月水金` など）
・曜日を変える：同じ名前でもう一度 `/habit add`
・やめる：`/habit remove`（記録は残ります）
・記録を見る：`/habit stats`（4週間分と30日の達成率）
習慣はボードの上にボタンで並び、2日以上続くと🔥が付きます。21時にまだの習慣があれば声をかけます。

**気をつけること**
・ボードは毎朝0時に出ます。0時までは前の日の扱いです。
・明日以降に入れたタスクは、その日になるまでボードに出ません。
・ボードが流れて見えなくなったら `/board` で出し直せます。
=====
## ⏰ #remind ― リマインダー
日時と用件を書くだけです。
```
明日9時 ゴミ出し
30分後 洗濯
毎週月曜8時 資源ごみ
平日 8時 メール
11/20 15:00 締切
```
・時刻を書かないと9時になります。
・入れた直後の返事にある「🗑️取り消す」で取り消せます。
・時間が来るとメンションし、「✅完了・10分後・1時間後・明日」のボタンが出ます。
・Bot が止まっていた間の分は、起動したときに遅れて知らせます。

**どこからでも**：`/remind 明日9時 ゴミ出し`
**一覧と取り消し**：`/reminders`
=====
## 🧾 #kakeibo ― 家計簿
**レシートの写真を送る**と、合計金額・日付・店名を読み取ります。写真はサーバーに保存されます。
**写真がないとき**は金額とメモを書きます：`680 昼食`

記録の下のボタン
・分類のボタン：押して分類を選びます。同じ店やメモには、次から同じ分類が自動で付きます。
・✏️：金額・日付・店・メモを直します（読み間違いはここで）。
・🗑️：記録を消します。

**集計**：`/kakeibo`（今月）、`/kakeibo 2026-10`（月を指定）。分類ごとの合計と、Excel で開ける CSV が出ます。
写真は明るく、まっすぐ、レシート全体が写っているほどよく読めます。

## 📚 #inbox と論文フォーラム ― 論文・リンク
**登録**：<#INBOX> に URL・arXiv・DOI を貼るだけです（`arxiv:2401.12345` でも可）。Cosense にページを作ります。重複していれば作らずに知らせます。
・論文なら、フォーラムに論文ごとのスレッドが立ちます。
・arXiv の論文は、序論の最後の段落・結論・図をスレッドに投稿します。
・DOI の論文などは、スレッドに **PDF を添付**すると同じことをします。

**読書の状態**：スレッドの最初の投稿の「📚積読・📖読書中・✅読了」を押します。Cosense のタグとフォーラムのタグも一緒に変わります。
**本棚**：`/tsundoku` で読書中と積読を一覧し、メニューから状態を変えられます。
**どこからでも登録**：`/clip URL`

## 🆕 arXiv の新着
毎朝、キーワードに合う新着を流します。
・📌：登録（Cosense にページを作ります）
・👎：見送り
=====
## 🔍 #search ― まとめて探す
書くとそのまま検索になります。Discord のメッセージ、Cosense、レシートの文字、論文 PDF をまとめて探します。
```
知識グラフ
@cosense 検索
"knowledge graph"
```
・`@cosense` `@discord` `@receipt` `@pdf` を付けると場所を絞れます。
・空白を含む語は `"` で囲みます。
・どこからでも：`/find 語`

**`/triage`**：Discord に貼ったまま Cosense に入っていないリンクを並べ、ボタンで Cosense に送れます。

## 📕 Kindle 日替わりセール
毎朝0時に、その日のセール本の書名・価格・リンクを流します。今すぐ見たいときは `/kindle_now`。

## 🛠️ その他
・`/arxiv_now`：arXiv の新着を今すぐ流す
・`/reindex`：検索の索引を作り直す（最初に一度）
